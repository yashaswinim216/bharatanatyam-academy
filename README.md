# 🌸 Kala Bharati
### Bharatanatyam Academy — Traditional Dance Learning Website

Kala Bharati is a responsive website designed for a Bharatanatyam academy that celebrates the beauty of Indian classical dance. It provides information about the academy's tradition, teachers, student learning levels, class timings, and trial-class enquiries through a clean, elegant interface inspired by classical dance and cultural heritage.

## ✨ Key Features

- **Academy Introduction** — Discover the academy's approach to Bharatanatyam and its artistic traditions.
- **Teacher Profiles** — Explore teacher details, experience, qualifications, and profile photographs.
- **Student Learning Groups** — View student categories, including Vidvat, Senior, Junior, Beginners, and New Joiners.
- **Interactive Category Filters** — Filter student groups to explore different learning levels.
- **Class Timetable** — View batch timings, class days, learning levels, and instructor assignments.
- **Trial-Class Booking Form** — Submit student details, age group, dance experience, preferred batch, and contact number.
- **Email Booking Notifications** — Send trial-class enquiry details through Google Apps Script integration, subject to successful configuration and deployment.
- **Responsive Design** — Access the website on desktop, tablet, and mobile devices.
- **Mobile Navigation** — Navigate website sections using a mobile-friendly menu.
- **Elegant Visual Design** — A classical aesthetic with decorative typography, dance imagery, and a refined layout.

> **Note:** Class timings, instructor assignments, and student information should be verified with the academy before publication. Email notifications depend on the correct configuration of Google Apps Script and successful email delivery.
